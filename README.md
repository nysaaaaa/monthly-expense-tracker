# Monthly Expense Tracker

## Project Overview

The Monthly Expense Tracker is a Python-based application designed to help users record, manage, search, and analyze their monthly expenses.

The project uses Python and CSV file handling to store expense records. Users can add multiple expenses, set a monthly budget, search expenses, calculate total spending, and check their budget status.

## Features

- Create and store expense records in a CSV file
- Enter user's name and monthly budget
- Add one or multiple expenses
- Categorize expenses
- Search expenses by person
- Search expenses by category
- Display all recorded expenses
- Calculate total expenses
- Check whether the monthly budget has been exceeded
- Delete all stored expense data
- Exit the application

## Expense Categories

The application supports the following categories:

- Food
- Transport
- Shopping
- Entertainment
- Education
- Bills
- Other
