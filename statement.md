# Project Statement

## Project Title

Monthly Expense Tracker using Python and CSV

## Problem Statement

Managing monthly expenses manually can make it difficult to keep track of spending and determine whether the monthly budget is being followed.

The Monthly Expense Tracker is developed using Python to provide a simple way to record and manage expenses. The program stores expense details in a CSV file and provides options to add, search, display, and calculate expenses.

It also allows users to set a monthly budget and check their spending against the budget.

## Scope

The scope of this project includes:

- Recording monthly expenses
- Storing expense information in a CSV file
- Adding single and multiple expenses
- Categorizing expenses
- Searching expenses by person
- Searching expenses by category
- Displaying all recorded expenses
- Calculating total expenses
- Setting a monthly budget
- Checking the budget status
- Deleting stored expense data

The project focuses on basic Python programming, loops, functions, conditional statements, file handling, and CSV operations.

## Target Users

The application is designed for:

- Students
- Individuals managing personal expenses
- Users who want a simple way to track monthly spending
- Beginners learning Python programming and file handling

## High-Level Features

### 1. Expense Management

Users can add one or multiple expense records to the tracker.

### 2. Expense Categories

Expenses can be classified into categories such as Food, Transport, Shopping, Entertainment, Education, Bills, and Other.

### 3. CSV Storage

Expense records are stored in a CSV file so that the information can be accessed and managed by the program.

### 4. Search

Users can search for expenses by person or by category.

### 5. Expense Calculation

The program calculates the total amount spent based on the stored expense records.

### 6. Budget Management

Users can set a monthly budget and check whether their total spending is within or above the budget.

### 7. Data Management

The program provides an option to display all expenses and delete all stored expense data.

## Expected Outcome

The project provides a simple command-line application for recording and managing monthly expenses while demonstrating the use of Python programming concepts and CSV file handling.
